# LLM 위키 플러그인 — 코딩 없이 클로드 앱으로 만드는 나만의 지식 창고

**자료는 계속 쌓이는데, 정작 필요할 때 못 찾나요?**
안드레 카파시(Andrej Karpathy)의 **LLM 위키(LLM Wiki)** 방식을 터미널·코딩 없이 **클로드(Claude) 데스크톱 앱**에서 바로 쓰게 만든 한국어 플러그인이에요.
자료 폴더에 글·PDF·메모를 넣고 "자료 정리해줘" 한마디면, 클로드가 주제별 위키 페이지로 정리하고 바뀐 내용까지 고쳐 둬요. 나중에 물어보면 정리된 페이지를 펴 보고 출처와 함께 답해요.

▶ **사용법 영상 (7분)**: https://youtu.be/9Nbh1Wf-h04 — 윤스쨩의 클코 교실

## ⬇️ 다운로드
- **[llm-wiki.plugin 받기 (최신)](https://github.com/yoonspower/llm-wiki-plugin/releases/latest/download/llm-wiki.plugin)**
- 파일 업로드가 안 되면 같은 내용의 **[llm-wiki.zip](https://github.com/yoonspower/llm-wiki-plugin/releases/latest/download/llm-wiki.zip)** 을 올려 보세요.

## 설치 (둘 중 하나)
1. **파일로 설치**: 클로드 데스크톱 앱 → 왼쪽 **사용자 지정(Customize)** → **플러그인(Plugins)** → 업로드 → 받은 파일 선택
2. **마켓플레이스로 설치**: 같은 플러그인 화면에서 **Add marketplace** → `yoonspower/llm-wiki-plugin` 입력 → `llm-wiki` 설치 (업데이트도 여기서 받아요)

## 쓰는 법 (3문장이면 끝)
1. 위키 전용 **프로젝트**를 만들고 **빈 폴더**를 연결해요.
2. 프로젝트 지침에 한 줄: `질문을 받으면 항상 위키/목차.md부터 보고 답해.`
3. **"위키 시작해줘"** → 자료 폴더·위키 폴더·목차가 생겨요.
4. 자료 폴더에 파일을 넣고 **"자료 정리해줘"** → 주제별 페이지, 세 줄 요약, 문장마다 출처.
5. 궁금한 건 그냥 물어봐요 → 답 끝에 `참고: [[페이지]]` 가 붙으면 위키를 보고 답한 거예요.
6. 가끔 **"위키 점검해줘"** → 서로 다른 말·오래된 내용·연결 안 된 페이지를 번호로 보여 주고, 고치기 전에 물어봐요.

## 플러그인 규칙
- 자료 폴더 원본은 읽기만 하고 절대 안 고쳐요.
- 한 페이지 = 한 주제, 맨 위 3줄 요약, 사실마다 출처.
- 내용이 서로 다르면 지우지 않고 `⚠️ 서로 다름` 으로 둘 다 적고, 나중 자료로 확인되면 `✅ 해결` 로 바꿔요(예전 줄은 남김).
- 새 자료가 5개보다 많으면 5개씩 나눠 정리해요.
- 주민번호·계좌번호·비밀번호·개인 연락처는 위키에 옮기지 않아요. 원본을 열기 전에도 먼저 물어봐요.
- 윈도우에서 깨지는 글자는 파일 이름에 안 써요. 옵시디언(Obsidian)으로 열어도 링크가 그대로 보여요.

## 솔직한 한계
- 클로드가 위키를 외우는 게 아니에요. 위키 폴더를 연결한 프로젝트에서 물을 때 펴 보고 답해요.
- 위키 파일은 내 PC에 있어서 PC와 데스크톱 앱이 켜져 있어야 해요.
- 클로드가 일하는 만큼 요금제 사용량을 써요. 처음엔 자료를 몇 개씩만 넣으세요.
- 메일 수만 통처럼 원본을 다 뒤져야 하는 일은 검색 도구가 더 잘해요.
- 회사 문서는 넣기 전에 회사 보안 규정을 먼저 확인하세요.

## 日本語で使う（0.2.0〜）
カルパシーの **LLMウィキ** を、ターミナルなしで Claude デスクトップアプリで使うプラグインです。日本語で話しかければ日本語で答え、日本語のフォルダを作ります。
1. ウィキ専用の **プロジェクト** を作り、**空のフォルダ** をつなぎます。
2. プロジェクトの指示に一行：`質問されたら、いつもウィキ/目次.mdを見てから答えて。`
3. **「ウィキを始めて」** → `資料/`・`ウィキ/目次.md`・`ウィキ/記録.md`・`はじめに.md` ができます。
4. 資料フォルダにファイルを入れて **「資料を整理して」** → テーマごとのページ、いちばん上に3行まとめ、文ごとに出典。
5. 知りたいことはそのまま質問 → 答えの最後に `参考：[[ページ]]` があればウィキを見て答えたしるしです。
6. ときどき **「ウィキを点検して」** → 食い違い・古い内容・リンクのないページを番号で見せて、直す前に聞きます。
- 内容が食い違うと消さずに `⚠️ 食い違い` で両方書き、あとの資料で確かめられたら `✅ 解決` に変えます（前の行は残します）。
- マイナンバー・口座番号・パスワード・個人の連絡先はウィキに写さず `個人情報あり（原本参照）` と書きます。
- インストールは上の「설치」と同じです（Customize → Plugins → アップロード、または Add marketplace → `yoonspower/llm-wiki-plugin`）。

## 테스트
가상 회사 자료 21개(PDF·워드·엑셀·CSV·메모)로 시험: 5개씩 나눠 정리, 서로 다른 말 2건 발견 → 공지로 해결, 원본 변경 0, 깨진 링크 0, 민감정보 옮김 0.

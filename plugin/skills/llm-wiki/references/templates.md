# Templates for the LLM wiki

Replace `YYYY-MM-DD` with today's date. Keep the wording as written; the user reads these files.
Korean wiki: use the Korean templates below. Japanese wiki: use the templates under "Japanese (日本語)" at the end.

## 위키/목차.md

```markdown
# 목차

질문을 받으면 여기부터 봐요. 페이지 이름 — 한 줄 설명.

> 답하는 규칙 (클로드용)
> - 위키 페이지만 보고 답해요. 자료 폴더 원본은 먼저 "원본에서 찾아볼까요?" 묻고, 좋다고 하면 봐요.
> - "민감 정보 있음 (원본 참고)"인 내용(연락처·주민번호 등)은 원본을 열기 전에 꼭 물어봐요.
> - 답 마지막 줄은 항상 `참고: [[페이지]] · [[페이지]]` 형식으로 써요. ("출처:"나 파일 경로 말고)
> - 나중에도 쓸 만한 답이고 아직 따로 페이지가 없으면, 그다음 줄에 "이 답을 위키 페이지로 저장할까요?"라고 물어요.

## 관리용
- [[기록]] — 위키에서 한 일을 날짜별로 적은 기록 (정리한 자료 목록)
```

Add category headings (예: `## 업무 절차`, `## 사람·업체`, `## 도구`, `## 사건·소식`) as pages appear.
Each line: `- [[페이지 이름]] — 한 줄 설명`.

## 위키/기록.md

```markdown
# 기록

한 일을 날짜별로 한 줄씩 덧붙이기만 해요. "자료 정리해줘" 때는 여기 이름이 없는 자료만 새로 읽어요.

- YYYY-MM-DD | 시작 | 자료 폴더와 위키 폴더를 만듦
```

Line formats:
- `- YYYY-MM-DD | 정리 | 자료/파일이름 → [[페이지]]·[[페이지]]`
- `- YYYY-MM-DD | 못 읽음 | 자료/파일이름 (이유)`
- `- YYYY-MM-DD | ⚠️ 서로 다름 | 무엇이 다른지 → [[페이지]]`
- `- YYYY-MM-DD | ✅ 해결 | 무엇이 확인됐는지 (출처) → [[페이지]]`
- `- YYYY-MM-DD | 질문 저장 | [[페이지]]`
- `- YYYY-MM-DD | 점검 | 고친 것 요약`

## 시작하기.md

```markdown
# 시작하기

이 폴더는 클로드가 대신 정리하는 나만의 지식 창고예요.
클로드가 외우는 게 아니라, 물어볼 때 이 위키를 펴 보고 답해요.

1. 모은 글·PDF·메모·문서를 **자료** 폴더에 넣어요.
2. 클로드에게 **"자료 정리해줘"** 라고 말해요.
3. 궁금한 건 그냥 물어봐요. 예) "OO 절차 알려줘"
4. 가끔 **"위키 점검해줘"** 라고 하면 틀린 곳·빠진 곳을 찾아줘요.

꼭 알아 두기
- 이 폴더를 연결한 곳(이 폴더로 만든 프로젝트)에서 물어봐야 위키를 봐요. 다른 대화에서는 몰라요.
- 프로젝트 지침에 "질문을 받으면 항상 위키/목차.md부터 보고 답해" 한 줄을 넣어 두면 더 확실해요.
- 답 끝에 "참고: [[페이지]]"가 있으면 위키를 보고 답한 거예요. 없으면 "위키 보고 답해줘"라고 다시 물어봐요.
- 페이지 수 제한은 없어요. 150개쯤부터 느려지면 목차를 주제별로 나누자고 할게요.

- 자료 폴더의 원본은 클로드가 절대 고치지 않아요.
- 정리된 내용은 **위키** 폴더에 있어요. 목차.md부터 보면 돼요.
- 처음엔 자료를 몇 개씩만 넣는 게 빨라요.
- 옵시디언(무료)으로 이 폴더를 열면 페이지 사이 연결을 그림으로 볼 수 있어요. 없어도 돼요.
```

```markdown
2. 핵심 한 줄 (출처: 파일이름)

## 내용
- 사실 한 줄. (출처: 파일이름)

## 관련 페이지
- [[다른 페이지]] · [[다른 페이지]]
```

# Japanese (日本語)

## ウィキ/目次.md

```markdown
# 目次

質問されたら、まずここを見ます。ページ名 — 一行の説明。

> 回答のルール（Claude用）
> - ウィキのページだけを見て答えます。資料フォルダの原本は、先に「原本で探しましょうか？」と聞いて、OKなら見ます。
> - 「個人情報あり（原本参照）」の内容（連絡先・マイナンバーなど）は、原本を開く前に必ず聞きます。
> - 答えの最後の行は、いつも `参考：[[ページ]] · [[ページ]]` の形で書きます。（「出典：」やファイルのパスではなく）
> - あとでも使えそうな答えで、まだ専用のページがなければ、次の行で「この答えをウィキのページに保存しますか？」と聞きます。

## 管理用
- [[記録]] — ウィキでやったことを日付ごとに書いた記録（整理した資料の一覧）
```

Add category headings (例: `## 仕事の手順`, `## 人・取引先`, `## ツール`, `## 出来事・お知らせ`) as pages appear.
Each line: `- [[ページ名]] — 一行の説明`.

## ウィキ/記録.md

```markdown
# 記録

やったことを日付ごとに一行ずつ書き足すだけです。「資料を整理して」のときは、ここに名前がない資料だけを新しく読みます。

- YYYY-MM-DD | 開始 | 資料フォルダとウィキフォルダを作成
```

Line formats:
- `- YYYY-MM-DD | 整理 | 資料/ファイル名 → [[ページ]]・[[ページ]]`
- `- YYYY-MM-DD | 読めない | 資料/ファイル名（理由）`
- `- YYYY-MM-DD | ⚠️ 食い違い | 何が違うか → [[ページ]]`
- `- YYYY-MM-DD | ✅ 解決 | 何が確認されたか（出典） → [[ページ]]`
- `- YYYY-MM-DD | 質問を保存 | [[ページ]]`
- `- YYYY-MM-DD | 点検 | 直したことの要約`

## はじめに.md

```markdown
# はじめに

このフォルダは、Claudeが代わりに整理してくれる自分だけの知識の倉庫です。
Claudeが暗記するのではなく、聞かれたときにこのウィキを開いて答えます。

1. 集めた文章・PDF・メモ・文書を **資料** フォルダに入れます。
2. Claudeに **「資料を整理して」** と言います。
3. 知りたいことは、そのまま聞きます。例）「〇〇の手順を教えて」
4. ときどき **「ウィキを点検して」** と言うと、間違い・抜けを探してくれます。

覚えておくこと
- このフォルダをつないだ場所（このフォルダで作ったプロジェクト）で聞いたときだけ、ウィキを見ます。ほかの会話では知りません。
- プロジェクトの指示に「質問されたら、いつもウィキ/目次.mdを見てから答えて。」と一行入れておくと、もっと確実です。
- 答えの最後に「参考：[[ページ]]」があれば、ウィキを見て答えたしるしです。なければ「ウィキを見て答えて」ともう一度聞きます。
- ページ数の上限はありません。150ページくらいから遅くなったら、目次をテーマごとに分けようと提案します。

- 資料フォルダの原本は、Claudeが絶対に書き換えません。
- 整理された内容は **ウィキ** フォルダにあります。目次.mdから見ればOKです。
- 最初は資料を数個ずつ入れるほうが速いです。
- Obsidian（無料）でこのフォルダを開くと、ページ同士のつながりを図で見られます。なくても大丈夫です。
```

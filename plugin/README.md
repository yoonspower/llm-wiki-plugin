# LLM 위키 (llm-wiki) 플러그인

클로드가 대신 정리하는 나만의 지식 창고. 안드레 카파시의 "LLM 위키" 방식을
코딩·터미널 없이 클로드 데스크톱 앱에서 쓰게 만든 플러그인이에요.
클로드가 외우는 게 아니라, 물어볼 때 정리된 위키를 펴 보고 출처와 함께 답해요.

## 준비물
- 클로드 데스크톱 앱 (맥·윈도우), 유료 요금제
- 위키로 쓸 빈 폴더 하나

## 쓰는 법
1. 플러그인 설치
2. 위키 전용 프로젝트를 만들고 빈 폴더를 연결
3. 프로젝트 지침에 한 줄: "질문을 받으면 항상 위키/목차.md부터 보고 답해"
4. **"위키 시작해줘"** → 자료 폴더, 위키 폴더, 목차, 기록이 생겨요
5. 자료 폴더에 글·PDF·메모를 넣고 **"자료 정리해줘"**
6. 궁금한 건 그냥 질문 → 위키 페이지를 보고 출처와 함께 답해요 (답 끝에 "참고: …")
7. 가끔 **"위키 점검해줘"** → 서로 다른 말, 오래된 내용, 연결 안 된 페이지를 찾아줘요

## 꼭 알아 두기
- 위키는 이 폴더를 연결한 곳에서만 봐요. 다른 대화에서는 몰라요.
- 답 끝에 "참고"가 없으면 위키를 안 본 거예요 → "위키 보고 답해줘"
- 페이지 수 제한은 없어요. 150개쯤부터 느려지면 목차를 주제별로 나눠요.
- 내 컴퓨터 폴더는 데스크톱 앱이 켜져 있어야 써요.

## 규칙 (플러그인에 들어 있음)
- 자료 폴더 원본은 읽기만 하고 절대 안 고쳐요
- 한 페이지 = 한 주제, 맨 위 3줄 요약, 사실마다 출처 표시
- 예전 내용과 다르면 지우지 않고 ⚠️ 서로 다름으로 나란히 적어요
- 새 자료가 5개보다 많으면 5개씩 나눠 정리해요
- 윈도우에서 깨지는 글자는 파일 이름에 안 써요
- 주민번호·계좌번호·비밀번호 같은 민감 정보는 위키에 옮기지 않아요

## 日本語
日本語で話しかければ、日本語で答えて日本語のフォルダを作ります（0.2.0から）。
1. ウィキ専用のプロジェクトを作り、空のフォルダをつなぎます
2. プロジェクトの指示に一行：「質問されたら、いつもウィキ/目次.mdを見てから答えて。」
3. **「ウィキを始めて」** → 資料/・ウィキ/目次.md・ウィキ/記録.md・はじめに.md ができます
4. 資料フォルダにファイルを入れて **「資料を整理して」** → テーマごとのページ、3行まとめ、文ごとに出典
5. 知りたいことはそのまま質問 → 答えの最後に「参考：[[ページ]]」があればウィキを見た答えです
6. ときどき **「ウィキを点検して」** → 番号つきで問題を見せて、直す前に聞きます
- 食い違う内容は消さずに「⚠️ 食い違い」、あとの資料で確かめられたら「✅ 解決」
- マイナンバー・口座番号・パスワード・個人の連絡先はウィキに写さず「個人情報あり（原本参照）」と書きます
- 韓国語のウィキ（자료/・위키/）はそのまま使えます。すでにあるウィキはフォルダ名を変えません
